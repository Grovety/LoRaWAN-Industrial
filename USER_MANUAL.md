# User Manual

## Start the Application

After the panel starts, the application opens a looping three-screen presentation.

Press and hold the **lower-right corner** of the touchscreen for **3 seconds** to open the HMI.

On the first startup, the application highlights this corner and displays a shortcut explanation. Tap **OK** to continue. Select **Don't show this again** before tapping OK if the explanation is no longer needed.

## Site Overview

The main screen shows the complete facility.

1. Check the top summary for online devices, warnings, and active alarms.
2. Tap a production area on the site map to open it.
3. Use the colored area marker to identify its current equipment health.

![Industrial site overview](images/site-overview.png)

## Zone Overview

The zone screen shows equipment cards for the selected production area.

1. Review the equipment, device, alarm, and main process summaries at the top.
2. Swipe horizontally when more equipment cards are available.
3. Tap an equipment card to open its detailed screen.
4. Tap **Back** to return to the site overview.

![Production area equipment](images/zone-overview.png)

## Equipment Detail

The equipment screen shows current operating information.

- Check the status chips for equipment health, operating state, communication state, and telemetry age.
- Review the main measurements and their status colors.
- Select an available metric above the chart to view its trend.
- Review the operating envelope and process context on the right side.
- If a guided scenario is active and this equipment is the root cause, tap **Recover Root Cause**.
- Tap **Back** to return to the zone.

![Detailed equipment status](images/equipment-detail.png)

## Run a Demonstration Scenario

1. Tap **DEMO** in the top bar.
2. Select **Auto** for continuous automatic simulation or **Manual** to choose a scenario.
3. In Manual mode, tap the required scenario.
4. Wait for the countdown to finish.
5. Follow the highlighted production area and equipment.
6. Observe each step in the cause-and-effect sequence.
7. Open the highlighted root-cause equipment.
8. Tap **Recover Root Cause** to complete the demonstration.

To leave a guided scenario, return to the Demo screen and select another mode or scenario.

## Settings

Tap the settings button in the upper-right corner.

### Wi-Fi

1. Open **Wi-Fi**.
2. Tap **Scan**.
3. Select a network.
4. Enter the password and tap **Connect**.

Use **Disconnect** to end the current connection or **Forget Wi-Fi** to remove the saved network.

### Time

Select the 12-hour or 24-hour clock format. When a network connection is available, the application synchronizes the clock and determines the local time zone.

### Brightness

Move the brightness slider to the required level. The selected value is saved and restored after restart.

## Return to the Presentation

Press and hold the **lower-right corner** of any HMI screen for **3 seconds**.

The application does not return to the presentation automatically. It remains in the HMI until the lower-right corner shortcut is used.
